When making git commits:
- Use conventional commit format: feat:, fix:, refactor:, docs:, chore:, style:, test:
- Write descriptive messages explaining WHAT changed and WHY
- Never commit node_modules, .env, .next, or dist directories
- Never commit with generic messages like "fix", "update", "changes", "wip"
- Commit after each meaningful change, not at the end of everything
- If a commit touches more than 5 files, consider if it should be split into smaller commits
